# Contributing

This repository is **public and open to contributions, but changes are accepted only through pull requests.** Direct pushes to `main` are disabled.

## How to contribute

1. **Fork** the repository.
2. Create a branch for your change.
3. For substantive points (a counter-example, a disputed step, a new section), **open an issue first** so we can discuss the direction.
4. Edit `the-liquidators-frontier.tex` (the PDF is regenerated from it). Keep the build clean: `pdflatex the-liquidators-frontier.tex` must compile with no errors.
5. Open a **pull request** describing the change and the reasoning. Reviews and merges are handled by the maintainers.

## What we're looking for

- Counter-examples or failure cases for the σ\* frontier and the effective-attachment claim.
- Extensions to the first-passage, clearing-capacity and cascade sections.
- Empirical liquidation data testing the effective-vs-contractual attachment gap.
- Composition with structural credit pricing (Merton / Black–Cox) and parametric calibration.

## Ground rules

- Keep claims verifiable — cite data, on-chain evidence, or a derivation.
- One idea per PR where possible; it makes review tractable.
- Be constructive. This is a working paper; disagreement with specifics is the point.

Contributions are accepted under the repository's CC BY 4.0 license, with attribution.
